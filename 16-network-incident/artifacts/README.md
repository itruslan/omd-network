# Артефакты инцидента (глава 16)

Здесь сохранённые улики учебного инцидента интернет-магазина: журналы, захваты
пакетов, снимки счётчиков и состояния. Задание, описание точек наблюдения и
происхождение каждого файла — в главе 16 курса «DevOps. Сети».

Работать можно на любой операционной системе и без прав `root`: захваты
читаются из файла. Нужны `tcpdump`, `jq`, при желании Wireshark.

| Файл | Точка наблюдения |
|---|---|
| `tickets.md` | обращения покупателей и письмо партнёра |
| `changes.md` | календарь изменений команды, время московское |
| `edge-access.log` | пограничный узел |
| `app.log` | Pod магазина на двух узлах |
| `partner.log` | API партнёра |
| `hubble-shop.json` | агенты Cilium на узлах кластера |
| `vpngw-inside.pcap` | VPN-шлюз, интерфейс в сторону кластера |
| `vpngw-tunnel.pcap` | VPN-шлюз, интерфейс в туннель |
| `flowlog-vpngw.txt` | тот же интерфейс: записи в формате журнала потоков |
| `metrics.txt` | снимки метрик и счётчиков раз в 15 секунд |
| `vpngw-state-start.txt`, `vpngw-state-end.txt` | VPN-шлюз до инцидента и после |
| `k8s-shop.txt` | снимок namespace `shop`, снят во время инцидента |
| `edge-waf.conf` | правила фильтра запросов на краю |

Журнал потоков получен из захвата, а обращения и письмо написаны по реальным
записям журналов: подробности — в разделе «Артефакты» главы.

В соседнем каталоге `lab` лежит генератор, которым всё это снято. **В нём
видно, какие неисправности внесены**: открывайте его после того, как оформите
разбор.
